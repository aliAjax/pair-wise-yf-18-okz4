# 镶嵌工坊排产台

替代白板的本地排产工具：给每件镶嵌活儿选择师傅、工位、日期、开始时段和预计时长，
师傅或工位撞时段时自动拦截并保留原排班；急件可顶掉未开工的普通任务；
待安排、今日排班、冲突清单共用同一份本地数据，重开浏览器仍可继续调整。
不接后端、不新增依赖。

## 排产规则

- 同一师傅 / 同一工位在半小时时段上不可重叠（首尾相接不算撞，如 09:00 接 09:00）。
- **普通任务相撞**：保留原排班不动，本次尝试被拒，写入冲突清单并注明与哪一单、在师傅还是工位上冲突。
- **急件顶单**：只可顶掉「未开工的普通任务」，被顶单回到待安排并自动登记顶单原因；
  已开工单、同为急件的单顶不动，排期被拦并记录。
- **改期 / 换人**：校验时先释放该单旧占用，成功才覆盖；被撞则原排班原样保留。
- 数据只存本机浏览器（localStorage 键 `inlay-workshop-scheduler:v1`），
  待安排池、排班日历、冲突清单共享一份状态。

## 代码结构（三个业务文件）

| 文件 | 职责 |
| --- | --- |
| `src/schedulingRules.ts` | 规则层（纯逻辑）：师傅/工位资料、半小时时段换算、撞单判定、急件可顶判定 |
| `src/schedulingStore.ts` | 存档层：localStorage 持久化、排期/改期/释放/顶单流程、冲突清单落账，发布订阅 |
| `src/SchedulingBoard.tsx` | 界面层：排产表单、实时撞单预演、排班日历、待安排池、冲突清单 |

`src/react-shim.d.ts` 是因当前脚手架未包含 `@types/react` 而补的本地最小类型垫片，
不属于业务文件，日后补入类型包可直接删除。

## 技术栈

React 19 + Vite + TypeScript（无新增依赖）

## 本地运行

```bash
npm install
npm run dev
```
