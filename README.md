# hxyfront-62006 镶嵌工坊排产台

面向珠宝镶嵌工坊的排产台，替代白板排班，避免同一师傅/工位的活儿撞时段。

## 功能

- **排产台**：选择工单、师傅、工位、时段（开始时间）和预计时长，确认后排入今日排班
- **撞单保护**：师傅或工位时段相撞时拒绝排班、保留原排班，并说明与哪一单冲突
- **急件顶单**：急件只可顶掉未开工的普通任务；被顶任务自动回到待安排并记录原因
- **改期/换人**：先释放旧占用再校验新时段，校验失败自动恢复原排班
- **三块共用一份本地数据**：待安排、今日排班、冲突清单均存于 localStorage，重开页面可继续调整

## 代码结构（规则 / 存档 / 界面各一个业务文件）

- `src/rules.ts` — 排产规则：冲突判定、急件顶单、先释放再校验、状态流转（纯函数）
- `src/storage.ts` — 存档：localStorage 读写与示例盘面
- `src/App.tsx` — 界面：排产表单、待安排、今日排班、冲突清单

## 技术栈

React + Vite + TypeScript，无后端、无新增依赖。
